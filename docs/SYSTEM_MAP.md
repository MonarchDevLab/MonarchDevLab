- **Primary Brand Glow (Orange):** `#FF642B` (Sunset Orange)
- **Primary Brand Glow (Cyan):** `#00EDFF` (Electric Cyan)

- **Core Languages:** TypeScript, JavaScript, PHP, HTML5, CSS3
- **Frameworks & Runtimes:** Next.js, React, Node.js
- **Styling:** Tailwind CSS, Vector SVG / SMIL Animation
- **Database & Backend:** PostgreSQL, Supabase
- **Edge & Cloud Infrastructure:** Cloudflare Workers & CDN
